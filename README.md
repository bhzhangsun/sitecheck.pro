# SiteCheck Pro - Shopify Store Audit Tool

A powerful web tool to audit Shopify stores in 30 seconds. Analyzes performance, SEO, mobile responsiveness, and conversion optimization.

## 🚀 Quick Deploy

Click the button below to deploy instantly to Vercel:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/bhzhangsun/sitecheck.pro)

## Features

- ⚡ **Performance Analysis** - Load speed, image optimization, Core Web Vitals
- 🔍 **SEO Audit** - Meta tags, headings, search visibility  
- 📱 **Mobile Check** - Responsive design, mobile usability
- 💰 **Conversion Review** - Checkout flow, trust signals, CTA optimization
- 📊 **Detailed Reports** - Actionable insights with priority levels

## Tech Stack

- Next.js 15 + React 19
- Tailwind CSS 4
- TypeScript
- Lucide Icons

## Local Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

Output will be in `dist/` folder.
